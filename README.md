# 🌤️ Taiwan Weather Forecast — 台灣多元氣象可視化與歷史觀測 Web App

> **AI 創新微課程：CWA API × JSON × Python × SQLite × Streamlit × Folium**  
> *從中央氣象署 Open Data 到全功能互動式氣象觀測與預報平台 · Code Smarter, Build a Better Tomorrow!*  

---

## 🌟 核心特色功能 (Key Features)

1. **🗺️ Folium 互動地圖五大熱力指標即時切換**
   - 支援一鍵無縫切換：**🌡️ 平均氣溫 (°C)**、**💧 相對濕度 (%)**、**🌫️ PM2.5 細懸浮微粒 (μg/m³)**、**🌧️ 累積降雨量 (mm)** 及 **☔ 降雨機率 (%)**。
   - 地圖圓形標記 (`CircleMarker`) 自動套用各指標標準色階，上方常駐顯示地名與當前指標數值徽章。
   - 點擊標記可展開完整氣象資訊彈窗，並自動以高亮左邊框突顯當前選定的熱力指標。
   - 頂部動態色彩圖例（Legend）與右側即時高低值排行榜隨所選指標即時連動。

2. **🛰️ 實測觀測與預報雙軌架構（支援過去歷史資料調閱）**
   - **實測與歷史觀測 (`O-A0001-001`)**：串接中央氣象署全臺 **876 個自動氣象測站**，取得實測氣溫、實測濕度、累積降雨量及當日極值（最高溫/最低溫）。
   - **一週天氣預報 (`F-D0047-091` / `F-C0032-003`)**：涵蓋全臺 22 縣市與 9 大分區未來一週氣象預測。
   - **歷史實測回溯**：自動在 SQLite 資料庫中保留並記錄歷史天數，日期選單具備清楚標註：
     - `📅 2026-09-27 (歷史實測 O-A0001-001)`
     - `📅 2026-09-28 (歷史實測 O-A0001-001)`
     - `📅 2026-09-29 (歷史實測 O-A0001-001)`
     - `📍 2026-09-30 (今日實測 O-A0001-001)`
     - `🔮 2026-10-01 ~ (未來一週預報)`

3. **📈 連續時間序列氣象走勢圖 (Altair)**
   - 走勢圖可切換繪製氣溫高低溫雙線圖、相對濕度折線圖、PM2.5 折線圖、累積降雨量長條圖及降雨機率折線圖。
   - 無縫串接「過去歷史實測 ➔ 今日實測 ➔ 未來預報」，完整呈現氣候演進走勢。

4. **🤖 AI 智慧生活與健康防護指南 (AI Assistant)**
   - 👕 **穿衣穿搭與溫差指南**：依據預報溫層與日夜溫差提供適當衣物搭配建議。
   - ☔ **出行、降雨量與雨具建議**：依據降雨機率與累積雨量提醒攜帶傘具或雨具。
   - 🟢 **PM2.5 空氣品質與健康防護**：依據環境部標準提供口罩配戴與開窗防護指引。
   - 💧 **相對濕度與居家環境建議**：依據室內外濕度提供除濕機設定與防霉建議。

## 🚀 快速啟動指南

### 1. 安裝所需相依套件

```bash
pip install -r requirements.txt
```

### 2. 同步氣象署資料至 SQLite 資料庫

```bash
python cwa_service.py
```
> 會自動連線至中央氣象署 Open Data API：
> - 實測觀測：`O-A0001-001` (全臺 876 自動氣象站)
> - 縣市預報：`F-D0047-091` (全臺 22 縣市未來一週預報)
> - 分區預報：`F-C0032-003` (臺灣 9 大分區未來一週預報)
> 整合解析後將過去實測與未來一週預報存入 `data.db` 中的 `TemperatureForecasts` 資料表。

### 3. 啟動 Streamlit 互動式 Web 網站

```bash
python -m streamlit run app.py
```
瀏覽器會自動開啟 `http://localhost:8501`。

## 📊 資料庫設計 (Step 9 & Schema Migration)

```sql
CREATE TABLE IF NOT EXISTS TemperatureForecasts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    regionName TEXT NOT NULL,          -- 地區/縣市名稱 (如：臺北市、中部地區...)
    dataDate TEXT NOT NULL,            -- 預報/觀測日期 (YYYY-MM-DD)
    minT REAL NOT NULL,                -- 最低氣溫 (°C)
    maxT REAL NOT NULL,                -- 最高氣溫 (°C)
    weather TEXT DEFAULT '',           -- 天氣現象描述 (如：晴時多雲、陣雨)
    humidity REAL DEFAULT 70.0,        -- 相對濕度 (%)
    pop REAL DEFAULT 0.0,              -- 降雨機率 (%)
    rainfall REAL DEFAULT 0.0,         -- 累積降雨量 (mm)
    pm25 REAL DEFAULT 15.0,            -- PM2.5 細懸浮微粒 (μg/m³)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(regionName, dataDate) ON CONFLICT REPLACE  -- 防止重複插入，自動保留歷史紀錄
);
```

## 🎨 地圖熱力視覺化色階標準 (Step 17)

### 1. 🌡️ 氣溫 (°C)
* 🔵 **寒冷**：$< 20^\circ\text{C}$ (`#2563eb`)
* 🟢 **舒適**：$20 \sim 25^\circ\text{C}$ (`#10b981`)
* 🟡 **溫暖**：$25 \sim 30^\circ\text{C}$ (`#f59e0b`)
* 🔴 **炎熱**：$> 30^\circ\text{C}$ (`#ef4444`)

### 2. 💧 相對濕度 (%)
* 🟠 **乾燥環境**：$< 50\%$ (`#f59e0b`)
* 🟢 **舒適適宜**：$50 \sim 70\%$ (`#10b981`)
* 🔵 **潮濕偏悶**：$70 \sim 85\%$ (`#0284c7`)
* 🔷 **極度潮濕**：$> 85\%$ (`#1e3a8a`)

### 3. 🌫️ PM2.5 細懸浮微粒 (μg/m³)
* 🟢 **良好**：$0 \sim 15.4$ (`#10b981`)
* 🟡 **普通**：$15.5 \sim 35.4$ (`#eab308`)
* 🟠 **對敏感族群不健康**：$35.5 \sim 54.4$ (`#f97316`)
* 🔴 **對所有族群不健康**：$54.5 \sim 150.0$ (`#ef4444`)
* 🟣 **非常不健康 / 危害**：$> 150.0$ (`#a855f7`)

### 4. 🌧️ 累積降雨量 (mm)
* ⚪ **無明顯降雨**：$0\text{ mm}$ (`#94a3b8`)
* 🟦 **微量降雨**：$0.1 \sim 5\text{ mm}$ (`#06b6d4`)
* 🔷 **小雨到中雨**：$5.1 \sim 15\text{ mm}$ (`#3b82f6`)
* 🟧 **大雨預警**：$15.1 \sim 35\text{ mm}$ (`#d97706`)
* 🟥 **豪大雨等級**：$> 35\text{ mm}$ (`#dc2626`)

### 5. ☔ 降雨機率 (%)
* ⚪ **極低機率**：$< 20\%$ (`#64748b`)
* 🟦 **低機率**：$20 \sim 39\%$ (`#06b6d4`)
* 🔷 **可能降雨**：$40 \sim 59\%$ (`#3b82f6`)
* 🔵 **高機率**：$60 \sim 79\%$ (`#2563eb`)
* 🟣 **極高機率**：$\ge 80\%$ (`#7c3aed`)

## 🛠️ 技術模組分工

- **`cwa_service.py`**：
  - 串接中央氣象署 CWA API（`O-A0001-001` 全測站觀測、`F-D0047-091` 22縣市預報、`F-C0032-003` 9分區預報）。
  - 自動處理 SSL 連線與 Fallback 機制、解析 876 測站實測數據、計算各縣市極值與生成歷史連續數據。
- **`database.py`**：
  - SQLite 連線池管理、自動執行 Schema 遷移（自動檢查並擴充缺漏欄位）。
  - 封裝多維度查詢（按地區、按日期、全表查詢），防範 SQL 注入。
- **`app.py`**：
  - 全功能 Streamlit 前端應用，包含 Folium 地圖、5 大指標熱力切換器、Altair 連續走勢折線圖、多功能預報表格（支援 CSV 下載）、4 大 AI 生活指南卡與後台 SQL 教學驗證。
